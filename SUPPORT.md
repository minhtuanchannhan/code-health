# Support

For installation problems, validation failures, incorrect findings, or feature requests, open a [GitHub issue](https://github.com/minhtuanchannhan/code-health/issues).

Include the plugin version, host product and version, operating system, audit scope, relevant non-sensitive logs, and minimal reproduction steps. Do not include credentials, private source code, personal data, or other secrets in a public issue.

Report suspected security vulnerabilities privately through [GitHub Security Advisories](https://github.com/minhtuanchannhan/code-health/security/advisories/new).
