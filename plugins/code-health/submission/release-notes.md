# Release Notes

## 0.1.0

Initial public submission of Code Health, a skills-only repository audit plugin for Claude, ChatGPT, and Codex.

- Supports changed, component, repository, and deep audit scopes.
- Reviews eight engineering health dimensions using concrete evidence.
- Normalizes and prioritizes findings with an explicit risk model.
- Keeps audit discovery read-only and separates remediation from verification.
- Includes a dependency-free baseline collector and no remote service or authentication requirement.
