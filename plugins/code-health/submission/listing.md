# Marketplace Listing

## Name

Code Health

## Short description

Evidence-backed code-health audits for repositories.

## Long description

Audit changed code, a component, or an entire repository using concrete evidence, risk-based prioritization, and explicit verification guidance. Code Health reviews security, reliability, architecture, maintainability, performance, scalability, testing, and developer experience without modifying production code during discovery.
