# Privacy Policy

Last updated: August 29, 2026

Code Health is a local, skills-only plugin. The plugin does not operate a remote service, create user accounts, collect telemetry, use advertising identifiers, or send repository data to the plugin developer.

When asked to run an audit, the plugin may read files and repository metadata that the user has made available to the host product. Its optional baseline collector writes repository metadata under `.code-health/runs/` in the repository being audited. It does not read environment-variable values, credentials, or unrelated files. Audit findings remain in the host product conversation unless the user asks to save them.

Claude, ChatGPT, Codex, source-control providers, and tools the user independently enables process data under their own terms and privacy policies. Users should not provide secrets or regulated data unless their organization has approved that processing.

Privacy questions may be reported through [GitHub Issues](https://github.com/minhtuanchannhan/code-health/issues).
